# 05 — Pilot Plan

**Phase 0 — build (wks 1–4):** program + matrix harness (every refusal case exercised on local
validator, mutation-tested guards), keeper (clearing solver + TWAP cross-check), minimal dApp
(commit/reveal client with local salt custody + auto-reveal bot).
**Phase 1 — devnet (wk 5):** 2 synthetic tokens, scripted whale/team/MM actors, 50+ batches,
chaos tests (keeper down mid-reveal, RPC loss, partial reveals).
**Phase 2 — audit (wks 6–12):** external firm on the frozen program; fixes at NEW id if material
(the lesson is institutional now).
**Phase 3 — mainnet pilot (wk 13+):** ONE token, allowlisted cohort (1–2 whales, the token's
team buyback wallet, 1 MM), max batch $50k, daily cadence, canary batch with our own dust first.
Success = 10 clean batches, honest post-vs-pool execution reports published per batch.
**Phase 4 — widen:** more tokens (listing gate discipline), raise caps stepwise, terminal SDK
conversations start only after Phase 3 receipts exist.

**Kill criteria (honest):** if 3 consecutive pilot batches fail to cross with real interest on
both sides, the cold-start thesis is wrong at current market size — stop, publish findings, keep
the tech shelved for the next cycle. No zombie mode.
